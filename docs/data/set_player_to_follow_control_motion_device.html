Set Player to Follow Control Motion Device

This server node is only available in Beyond Mode.

Set a player to follow a control motion device entity.

Input Parameters

  • Player Entity (Entity) - Player entity to follow the control motion device
  • Control Motion Device Entity (Entity) - Entity with a control motion device component

Usage

Luna VIII introduced control motion devices. An entity can have a control motion device component, then this entity's movement can be controlled directly by players instead of controlling Manekin/Manekina character. This feature can be used to create a vehicle that can be driven by players.

Use this node to make a player follow a control motion device entity. The camera will now follow the entity, the character entity will not be visible, and the character entity's location will be kept same as the following entity.

To make character visible again and get the camera back on character, use Set Player to Leave Control Motion Device.

Example

When the tab is selected by a player, we set the player to control this control motion device entity and then follow this entity.

Notes

  • Player Entity must be a player entity. If Player Entity is a stage, character, object, or creation entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • If Control Motion Device Entity is not currently on the stage, this node raises "Entity does not exist" error.
  • If Control Motion Device Entity does not have a control motion device, this node is a no-op.
  • If the player does not currently control any control motion device, this node is a no-op.
  • If Control Motion Device Entity is currently not controlled by the player, but player is currently controlling another control motion device, this node surprisingly works. With this, you can get into a weird situation where you only control entity A, but follows entity B.
  • If the location and the rotation of the character is queried with Get Entity Location and Rotation while the player follows a control motion device entity, it returns the same location and rotation as the control motion device entity.

Performance

This node took ~3 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
