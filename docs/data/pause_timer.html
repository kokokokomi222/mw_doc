Pause Timer

Pauses a timer.

Input Parameters

  • Target Entity (Entity) - Entity that has the timer to pause.
  • Timer Name (String) - Name of the timer.

Usage

This node pauses a timer that was started by Start Timer. Paused timer does not trigger When Timer Is Triggered event anymore. To resume the timer, use Resume Timer.

If you would like to completely delete all timer state and never resume it, use Stop Timer instead.

Example

In this example, we pause a timer named spawn_coin while a menu UI is opened. The timer is resumed when the menu UI is closed.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error and continues execution.
  • If there is no timer with name Timer Name on the entity, this node is no-op.
  • If the timer with name Timer Name is already paused, this node is no-op.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
