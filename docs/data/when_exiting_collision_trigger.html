When Exiting Collision Trigger

Triggers when an entity exits a collision trigger.

Output Values

  • Exiting Entity (Entity) - Entity that exited the collision trigger.
  • Exiting Entity GUID (GUID) - GUID of the above entity. 0 if created dynamically.
  • Trigger Entity (Entity) - Entity that has the collision trigger component.
  • Trigger Entity GUID (GUID) - GUID of the above entity. 0 if created dynamically.
  • Trigger ID (Integer) - ID of the collision trigger. e.g. 1

Usage

Collision triggers are used to detect whether an entity is within certain geometry. Collision triggers can be configured in the collision trigger component.

Use this node to listen to the event when an entity exits a collision trigger, i.e. when the exiting entity's collision trigger source no longer collides with the trigger entity's collision trigger. This node must be in a node graph that is mounted on the entity with collision trigger component.

Notes

  • Collision triggers can be configured to only trigger with specified type of entities (characters, objects, and/or creations). If the exiting entity is not one of the specified type, this node will not trigger.
  • Characters and creations have their inherent collision trigger source geometry, so nothing needs to be configured on characters and creations to make this node function. However, one needs to add collision trigger source component for object entities to make this node function. Characters and creations can also add additional collision trigger source component.
  • This node triggers if an entity is destroyed or removed while colliding with the trigger geometry.

Performance

This node took ~5 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
