Activate/Disable Extra Push Collision

This documentation was published soon after the release of this node. Some of the information may be inaccurate. Let me know if you find something wrong.

Sets extra push collidability.

Input Parameters

  • Creation Entity (Entity) - Complex creation entity to set the push collidability for.
  • Extra Push Collision ID (Integer) - ID for the extra push collision. e.g. 1
  • Activate (Boolean) - If Yes, push collision is enabled. If No, it is disabled.

Usage

v7.2 introduced push collision, which can be configured for complex creation entities. Each entity has one to several native collision geometry that can be independently enabled. This defines collision with characters or other creations. If the push collision is turned off, this complex creation entity can walk through characters and other creations, but it will still collide with object entities and react to creation disruptor device.

Complex creations can also have extra push collision component, adding more push collision geometry.

Use this node to either enable or disable this extra push collisions. You may want to consider using decorations instead, but decoration collisions cannot be toggled from node graphs.

Notes

  • If Target Entity is not an existing entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have an extra push collision component, this node raises "Entity component does not exist" error.
  • If Extra Push Collision ID is not an ID of an extra push collision, this node is no-op.

Performance

This node took ~3 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
