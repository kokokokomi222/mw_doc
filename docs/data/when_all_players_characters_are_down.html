When All Player's Characters Are Down

Triggers when all characters are downed for a player.

Output Values

  • Player Entity (Entity) - Player entity that has the downed characters.
  • Reason (Enumeration) - One of Node Graph Triggered, Normal Defeat, or Abnormal Defeat

Usage

Use this node to listen to the event when all characters are downed for a player. This node must be mounted on the player entity. Consider using When the Character Is Down instead.

Notes

  • This node is triggered after the character death animation concludes and as it enters the revive screen.

Performance

This node took ~7 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
