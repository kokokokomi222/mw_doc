Sort Dictionary by Key

Get the keys and the values of a dictionary, sorted by key.

Input Parameters

  • Dictionary (Generic) - Dictionary to get the keys and values from. The type of the key must be integer.
  • Sort By (Enumeration) - Must be one of Sorting Rules_Ascending or Sorting Rules_Descending

Output Values

  • Key List (Generic) - List of keys in the dictionary, sorted by key
  • Value List (Generic) - List of values in the dictionary, sorted by key

Usage

This node lets you sort the key-value pairs by key. However, the usage is very limited, because it only allows integer for the key.

Example

In this example, we have a dictionary {4:"quadruple", 2:"double", 3:"triple"}. We sort the dictionary by key in the increasing order and print the values. The result in the log is "double", "triple", "quadruple", because 2 < 3 < 4.

Notes

  • It's unusual that this is an execution node instead of a query node. It does not modify any state or have side effects. It may be to keep the reference of the output, so that this node is not repeatedly called.
  • Changing the type of Dictionary will change the type of Key List and Value List, and vice versa.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~11 units on average. For a dictionary with 100 key-value pairs, this node took ~140 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
