Recover HP Directly

Heals without ability unit.

Input Parameters

  • Recover Initiator Entity (Entity) - Define initiating entity for this HP recovery. This is passed to When HP Is Recovered and When Initiating HP Recovery. Default is the entity that mounts this node graph.
  • Recover Target Entity (Entity) - Target entity to recover HP for.
  • Recovery Amount (Floating Point Numbers) - Amount of HP to recover. The final healing amount may change from healing bonus and incoming healing bonus. See notes below.
  • Ignore Recovery Amount Adjustment (Boolean) - If Yes, healing bonus and incoming healing bonus are ignored.
  • Aggro Generation Multiplier (Floating Point Numbers) - Multiplier value for custom aggro.
  • Aggro Generation Increment (Floating Point Numbers) - Additive value for custom aggro.
  • Healing Tag List (String List) - Tags associated with this healing. This is passed to When HP Is Recovered and When Initiating HP Recovery.

Usage

This node lets you heal entities without using Recover HP, which requires configuring a recover HP ability unit. This node is more expressive since it can specify all parameters in the runtime, and it can be mounted on any entity.

Notes

  • If Recover Initiator Entity does not exist, this node raises "Entity does not exist" error.
  • If Recover Initiator Entity is a stage or player entity, this node raises "Entity does not exist" error (which can be misleading).
  • If Recover Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Recover Target Entity is a stage or player entity, this node raises "Entity does not exist" error (which can be misleading).
  • If Recover Target Entity has "Special Status: Cannot recover HP" unit status effect, this node is no-op.
  • If Recovery Amount is negative, it is clamped to 0. When HP Is Recovered and When Initiating HP Recovery still triggers in this case.
  • Documentation regarding aggro will be updated later.
  • A green effect is played on Recover Target Entity and displays the effective healing amount in green text if this node successfully runs with more than 0 recovered HP. The displayed healing amount is rounded down to an integer (this rounding behavior differs from damage text). If the healing amount gets rounded down to 0, it will show 1 instead.
  • The healing formula is: 
      healing_adjustment = healing_bonus_of_healer + incoming_healing_bonus_of_target
  final_healing_amount = recovery_amount * (1 + healing_adjustment)
    For example, if Recovery Amount is 1000, the healing bonus of the healer is 85.9%, and the incoming healing bonus of the target is 52%, the effective healing amount is 1000*(1+0.859+0.52) = 2379. Note that healing bonus is a separate stat from incoming healing bonus. Healing bonus is available as unit status effect as "Healing Effect Adjustment Rate", and incoming healing bonus as "Healing Received Adjustment Rate". In classic mode, healing bonus and incoming healing bonus from ascension passives, talents, constellations, weapon passives, and artifact set effects all apply for this node. If the ability unit is configured so that "Ignore Recovery Adjustment" is set to No, then the final healing amount is just simply Recovery Amount without any adjustment, ignoring healing bonus and incoming healing bonus. See Healing for detail.

Performance

This node took ~16 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
