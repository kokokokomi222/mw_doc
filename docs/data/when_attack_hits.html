When Attack Hits

Triggers when an entity initiates an attack.

Output Values

  • Event Source Entity (Entity) - Entity that initiated the attack.
  • Event Source GUID (GUID) - GUID of the above entity. 0 if it was dynamically created.
  • Hit Target Entity (Entity) - Entity that was attacked.
  • Damage (Floating Point Numbers) - Effective damage amount dealt. See notes for detail.
  • Attack Tag List (String List) - List of tags associated with this attack.
  • Elemental Type (Enumeration) - One of Pyro, Hydro, Anemo, Electro, Dendro, Cryo, Geo, None.
  • Elemental Attack Potency (Floating Point Numbers) - Elemental attack potency value of the attack. Unit is 1/25 gauge unit. See notes for detail.

Usage

Use this node to listen to the event when the entity attacks another entity. This node must be mounted on the source of the attack. This attack can come from

  • Initiate Attack
  • Various character skill client nodes.
  • Characters skills/bursts/passives/constellations, weapon passives, or artifact set passives in classic mode.
  • Transformative elemental reactions (e.g. swirl, bloom).

Notes

  • Event Source Entity and Event Source GUID may not be the same as the self entity,
  • If Hit Target Entity has "Special Status: Invincible", this event triggers with Damage equal to 0.
  • If Hit Target Entity has "Special Status: Invincible", this event does not trigger.
  • If Hit Target Entity has "Special Status: HP Locked", this event triggers with Damage equal to 0.
  • If Hit Target Entity has "Special Status: HP Cannot Drop Below Specified Value", this event triggers with the full damage, but the HP lost may be less or even 0.
  • Elemental Attack Potency is the amount of elemental gauge applied by this attack. 25 is 1 unit of gauge (1U), which is the unofficial unit that Genshin community uses. More gauge means the elemental aura will last longer. More gauge also means it will cancel out other elemental aura more if it reacts with that element. The precise gauge mechanism is very complex. See Elemental Gauge Theory for detail.
  • If current HP of Hit Target Entity is queried with Get Object Attribute, Get Character Attribute, or Get Creation Attribute in this event, it shows the HP after the damage is dealt. If the damage was fatal, the Hit Target Entity does not exist on the field and HP cannot be queried.
  • This node does not trigger with HP Loss.
  • This event will trigger for transformative reaction, if Event Source Entity initiated the reaction.

Performance

This node took ~10 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
