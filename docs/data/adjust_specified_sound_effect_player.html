Adjust Specified Sound Effect Player

Adjusts the volume and playback speed of a looping sound effect.

Input Parameters

  • Target Entity (Entity) - Entity that has the looping sound effect player.
  • SFX Player ID (Integer) - ID of the looping sound effect player.
  • Volume (Integer) - Volume of the sound. 0 means mute, 100 means full gain. This value scales the amplitude linearly. Must be between 0 and 100, inclusive.
  • Playback Speed (Floating Point Numbers) - Speed to play the sound at. 1.0 means default speed. Must be between 0.5 and 2.0, inclusive.

Usage

This node lets us adjust the volume and speed of a looping sound effect played by Add Sound Effect Player.

SFX Player ID can be obtained from Add Sound Effect Player.

Notes

  • If Target Entity is not an entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have the SFX Player component, this node raises "Entity component does not exist" error.
  • If SFX Player ID is not an ID for a currently playing looping sound effect, this node is no-op.
  • If Volume is negative or if it exceeds 100, this node is no-op.
  • Because Volume scales the amplitude linearly, it does not scale linearly with human perception, which is logarithmic. If you are making a volume slider, you may want to account for this. See Adjust Player Background Music Volume for an example.
  • If Playback Speed is less than 0.5 or greater than 2.0, this node is no-op.

Performance

This node took ~5 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
