Clear Looping Special Effect

Clear a looping effect from an entity.

Input Parameters

  • Special Effect Instance ID (Integer) - Instance ID that was returned from Mount Looping Special Effect
  • Target Entity (Entity) - Entity that has the looping effect mounted

Usage

Use this node to clear a looping effect from an entity that was mounted with Mount Looping Special Effect. Consider using Clear Looping Special Effect instead, if you would like to clear potentially many instances of a looping effect at once.

Example

In this example, a "Hydro Shield" effect is played when a tab is selected on the entity. It is cleared when the tab is selected again.

Notes

  • If Special Effect Instance ID is not an instance ID of a mounted effect for the entity, this node is no-op.
  • If Target Entity does not exist, this node raises "Entity does not exist" error.

Performance

This node took ~5 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
