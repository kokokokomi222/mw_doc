Clear Special Effects Based on Special Effect Assets

Clear looping effects from an entity by effect ID.

Input Parameters

  • Target Entity (Entity) - Entity to clear the looping effects from.
  • Special Effects Asset (Config ID) - ID of the looping effect. e.g. 10001103

Usage

Use this node to clear looping effects from an entity that was mounted with Mount Looping Special Effect. Any looping effect with the specified effect asset ID will stop playing from the entity. In order to more precisely specify which effect to clear. Use Clear Looping Special Effect instead.

Example

In this example, a "Pyro Up Buff" effect is mounted every three seconds. Using the tab clears all the accumulated effects.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Special Effects Asset is not an ID of a looping effect, this node is no-op.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
