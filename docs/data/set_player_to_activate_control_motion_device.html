Set Player to Activate Control Motion Device

This server node is only available in Beyond Mode.

Set control motion devices for a player.

Input Parameters

  • Player Entity (Entity) - Player entity to change the control motion devices for
  • Control Motion Device Entity List (Entity List) - List of entities with a control motion device component

Usage

Luna VIII introduced control motion devices. An entity can have a control motion device component, then this entity's movement can be controlled directly by players instead of controlling Manekin/Manekina character. This feature can be used to create a vehicle that can be driven by players.

Use this node to set the control motion device entities to control for a player.

This node only sets the control of control motion devices. To change the camera to the control motion device and to hide the character from the stage, use Set Player to Follow Control Motion Device after calling this node.

This node can also be used to return the control to the character by passing an empty list to Control Motion Device Entity List. In general, you should also call Set Player to Leave Control Motion Device at this time.

Example

In this example, two entities with GUID 1077936475 and 1077936478 each have a control motion device. When the tab is selected by a player, we set the player to control these two entities. Both entities will be controlled together with the same input. Player's character remains on stage and the camera still stays on the character, but the player input does not control the character anymore. To make the player's camera follow one of the control motion device entity and make the character disappear, use Set Player to Follow Control Motion Device.

Notes

  • Player Entity must be a player entity. If Player Entity is a stage, character, object, or creation entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • If one of the entity in Control Motion Device Entity List is not currently on the stage, this node raises "Entity does not exist" error.
  • If one of the entity in Control Motion Device Entity List does not have a control motion device, this node is a no-op.
  • Leave Control Motion Device Entity List empty to return the control to the player's character.
  • If you are controlling and following a control motion device entity, and then call this node with empty list, then the player is stuck in a position where the player is still following the entity, but the control is on player's character. As a result, player cannot move at all. You should be calling Set Player to Leave Control Motion Device at the same time as well (the order of this node and Set Player to Leave Control Motion Device does not matter).
  • If the length of Control Motion Device Entity List is greater than 4, this node is no-op. Up to 3 control motion devices can be controlled by a player at once.

Performance

This node took ~17 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
