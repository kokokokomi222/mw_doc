Player Plays One-Shot 2D Sound Effect

Play a 2D sound effect.

Input Parameters

  • Target Entity (Entity) - Player entity to play the sound for.
  • Sound Effect Asset Index (Integer) - ID of the sound asset. e.g. 50925
  • Volume (Integer) - Volume of the sound. 0 means mute, 100 means full gain. This value scales the amplitude linearly. Must be between 0 and 100, inclusive.
  • Playback Speed (Floating Point Numbers) - Speed to play the sound at. 1.0 means default speed. Must be between 0.5 and 2.0, inclusive.

Usage

This node is a simple way to play a sound effect. The sound will only play once. It will not apply 3D sound effect, so it will just play the sound in mono without any attenuation by distance. With this node, you can also play a sound for just one player.

If you would like to repeat the sound on loop or use 3D sound effect, use Add Sound Effect Player instead. If you want to play music, use Set Player Background Music instead.

Example

In this example, we play a sound asset 50918 (Hint UI_Heavy_Crafting Complete) for the player that select the tab. It plays at volume 50 (half the amplitude, i.e. ~6dB softer than full gain). The sound plays at 1.5 times the speed.

Notes

  • If Target Entity is not a player entity, this node raises "Entity does not exist" error (can be misleading because the entity may exist).
  • If Sound Effect Asset Index is not an ID for a sound, this node is no-op.
  • If Volume is negative or if it exceeds 100, this node is no-op.
  • Playback Speed is less than 0.5 or greater than 2.0, this node is no-op.
  • Unlike music, Playback Speed appears to apply pitch correction. Faster speed does not mean that the pitch is higher.

Performance

This node took ~3 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
