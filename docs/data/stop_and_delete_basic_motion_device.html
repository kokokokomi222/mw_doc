Stop and Delete Basic Motion Device

Stop a basic motion device.

Input Parameters

  • Target Entity (Entity) - Entity to stop the basic motion device for
  • Motion Device Name (String) - Name of the motion device, as specified in the basic motion device component
  • Stop All Basic Motion Devices (Boolean) - If set to yes, stops all basic motion devices on this entity. If set to no, stops only the basic motion device whose name matches the above input name.

Usage

This node is used to completely stop a basic motion device. If you may want to resume the motion later, use Pause Basic Motion Device instead.

The name of this node is little misleading: it does not "delete" basic motion device from the component altogether. It can still start the basic motion device later with the same name. This node simply "deletes" the currently running instance, so that it cannot be resumed from where it left off.

A basic motion device can be started at the start of the stage from the basic motion device component. It can also start with Activate Basic Motion Device.

Notes

  • If Target Entity does not have the basic motion device component, this node raises "Entity component does not exist" error.
  • If there is no running basic motion device with name Motion Device Name, this node is no-op.

Performance

This node took ~17 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
