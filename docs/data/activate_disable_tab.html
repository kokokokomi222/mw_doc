Activate/Disable Tab

Activate/disable a tab.

Input Parameters

  • Target Entity (Entity) - Entity with tab component
  • Tab ID (Integer) - ID of the tab. e.g. 1
  • Activate (Boolean) - If yes, activate the tab. If no, deactivate the tab.

Usage

Tab component is used to give selectable options to players. Use this node to activate or disable tabs from a node graph.

Example

In this example, we show a text bubble when the tab is selected, and then we disable that tab.

Notes

  • If Target Entity does not have the tab component, this node raises "Entity component does not exist" error.
  • If the entity does not have a tab with Tab ID as ID, this node is no-op.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
