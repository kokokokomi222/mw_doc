Get List of Player Entities on the Field

Gets list of players.

Output Values

  • Player Entity List (Entity List) - List of all player entities.

Usage

Use this node to get the list of players that are currently connected to the stage.

Example

In this example, we show a UI control to every player when the tab is selected.

Notes

  • If a player was in the lobby but has not loaded in to the stage yet (e.g. game client crashing), this player is not in Player Entity List. Players are given 10 minutes to load in to the stage, after which the player will not be able to load in to the stage.
  • If a player left the stage, this player is not in Player Entity List.
  • If all characters of a player is down, this player is still in Player Entity List.
  • Query Game Mode and Player Number returns the player number that was in the room when the stage began, so this number does not change while the stage runs, and it may not match the length of Player Entity List.
  • The order of players is not by ID, but the order of players does not change while the stage runs. More testing is needed to figure out what decides the order of players.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
