When Player Is Abnormally Downed and Revives

Triggers when a character is abnormally downed and revived.

Output Values

  • Player Entity (Entity) - Player entity that has the abnormally downed character.

Usage

Use this node to listen to the event when all characters are abnormally downed for a player and then revived. This can happen in multiple ways:

  • Drowning by running out of stamina while swimming.
  • Falling too far down the stage.

Dying to electro-charged water or burning grass may count too, but I was not able to set up a test for this.

This node must be mounted on the player entity.

Notes

  • This node is triggered when the revive initiates as the loading screen starts to show, not when the loading screen goes away.
  • Abnormally down from falling seems to occur when the character reaches around -2048 in y coordinate.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
