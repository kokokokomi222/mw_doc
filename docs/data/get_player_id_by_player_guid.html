Get Player ID by Player GUID

Gets the player ID from player GUID.

Input Parameters

  • Player GUID (GUID) - GUID of a player entity. e.g. 1086324738

Output Values

  • Player ID (Integer) - ID of the player. It ranges from 1 to 8, inclusive.

Usage

Use this node to get the player ID from player GUID. ID of a player is the slot they occupied in the room.

In this example, we print the ID of the player that selected this tab.

Notes

  • If Player GUID is not a GUID for a player, this node returns 0.
  • Player GUIDs are fixed for all stages. Player 1's GUID is always 1086324738 and the next player's GUID is 1 more than the previous player's GUID.
