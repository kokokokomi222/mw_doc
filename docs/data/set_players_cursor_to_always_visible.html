Set Player's Cursor to Always Visible

This server node is only available in Beyond Mode.

Sets cursor visibility.

Input Parameters

  • Player Entity (Entity) - Entity of the player to set the cursor visibility for.
  • Always Show Cursor? (Boolean) - Yes to always show cursor. No otherwise.

Usage

Luna VIII introduced various features involving cursors. Cursor settings can be configured in the player detail panel. "Always Show Cursor" can be set to Yes in order to make the cursor always visible. This node lets you toggle this setting from node graphs.

If cursor is visible, cursor coordinates and its hit results can also be queried from client node graph.

With keyboard/mouse input, players normally hold alt key to bring out the cursor so UI controls can be clicked. However, the visible cursor behaves little differently than the alt-hold cursor: visible cursor still controls the camera, but the alt-hold cursor does not control the camera. Cursor coordinates and hit results can be queried in the client node graph for visible cursor, while alt-hold cursor cannot be queried. Visible cursor can also be configured to click through UI controls using Set Player's Cursor to Click Through UI Controls. Both visible cursor and alt-hold cursor can leave the Genshin window.

Testing is needed for controllers and mobile devices.
