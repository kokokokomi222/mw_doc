Increase Player's Current Class EXP

This server node is only available in Beyond Mode.

Increase player's class EXP.

Input Parameters

  • Target Player (Entity) - Player entity to change the class level EXP for.
  • EXP (Integer) - Amount of EXP.

Usage

Use this node to change the level of player's class. Note that each class has its own level, so the level may change if the class is changed using Change Player Class.

You may want to use Change Player's Current Class Level instead.

Example

In this example, we have a node graph mounted on the stage. When a creature that mounts this node graph is destroyed and the attacker was a player, we increase that player's class EXP by the custom variable exp of the destroyed entity.

Notes

  • If Target Player does not exist, this node raises "Entity does not exist" error.
  • If Target Player is not a player entity, this node is no-op.
  • If EXP is negative, this node is no-op.
  • If EXP has excess EXP value after gaining a level, the rest of the EXP is added to the current class EXP. For example, let's say a class takes 100 EXP to level to 2, 400 to 3, and 900 to 4. We have a player with level 1 with no EXP. If EXP is 1250, the player will level to 3 and have 1250-100-400=750 EXP, only 150 more EXP away from leveling to 4.
  • Player's class level cannot exceed the maximum level configured for the class.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
