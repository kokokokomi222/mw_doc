Query Game Time Elapsed

Gets elapsed time since game started.

Output Values

  • Game Time Elapsed (Integer) - Number of seconds since the game started. In the unit of seconds.

Usage

Use this node to get how long the game has been running.

If you want to measure the duration of a span of time within a game, it is more precise to use Get Current Global Timer Time, as it outputs the time in seconds as float.

Notes

  • If the game is paused by a deck selector or a floating interacting page in single player, this timer is also paused.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
