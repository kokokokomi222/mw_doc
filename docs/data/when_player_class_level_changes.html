When Player Class Level Changes

This server node is only available in Beyond Mode.

Triggers when player's level changes.

Output Values

  • Event Source Entity (Entity) - Player entity that changed its class level.
  • Event Source GUID (GUID) - GUID of the player entity.
  • Pre-Change Level (Integer) - Level of the player class before the level change.
  • Post-Change Level (Integer) - Level of the player class after the level change.

Usage

Use this node to listen to player's class level change. This can occur from Change Player's Current Class Level or Increase Player's Current Class EXP.

In this example, we modify the custom variable world_level on the stage when the player level changes.

Notes

  • Event Source Entity and Event Source GUID may not be the same as the self entity, if it was forwarded by Forwarding Event.
  • If Change Player's Current Class Level is called where the changed level is same as the previous level, then this node does not trigger.

Performance

This node took ~3 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
