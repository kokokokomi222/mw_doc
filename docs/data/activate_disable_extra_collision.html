Activate/Disable Extra Collision

Sets extra collidability.

Input Parameters

  • Target Entity (Entity) - Object entity to set the extra collision for.
  • Extra Collision ID (Integer) - ID for the extra collision. e.g. 1
  • Activate (Boolean) - If Yes, extra collision is enabled. If No, it is disabled.

Usage

Native collision is used so that characters can collide with the entity. Extra collision component can be used to add or change the collision geometry.

Use this node to either enable or disable this extra collisions.

You may want to use decorations instead, which can be configured under model. If you need to detect whether an entity is within certain geometry, use collision trigger component instead.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Target Entity does not have the extra collision component, this node raises "Entity component does not exist" error.
  • If Extra Collision ID is not an ID of an extra collision, this node is no-op.

Performance

This node took ~3 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
