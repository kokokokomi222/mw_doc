Get Player GUID by Player ID

Gets the player GUID from player ID.

Input Parameters

  • Player ID (Integer) - ID of a player. It ranges from 1 to 8, inclusive.

Output Values

  • Player GUID (GUID) - GUID of the player entity. e.g. 1086324738

Usage

Use this node to get the player GUID from player ID. Player ID is the slot.

Example

In this example, we show a UI control for player 1 when the tab is selected.

Notes

  • If Player ID is less than 1 or greater than 8, this node returns 0.
  • If player slot with Player ID was not occupied by a player when the stage began, this node still returns the correct GUID.
  • If player with Player ID left the stage, this node still returns the correct GUID.
  • Player GUIDs are fixed for all stages. Player 1's GUID is always 1086324738 and the next player's GUID is 1 more than the previous player's GUID.
