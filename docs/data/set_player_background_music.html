Set Player Background Music

Plays a music.

Input Parameters

  • Target Entity (Entity) - Player entity to play the music for.
  • Background Music Index (Integer) - ID of the music. e.g. 10109
  • Start Time (Floating Point Numbers) - Time to start the music at. Unit is seconds.
  • End Time (Floating Point Numbers) - Time to stop the music at. Unit is seconds.
  • Volume (Integer) - Volume of the music. 0 means mute, 100 means full gain. This value scales the amplitude linearly. Must be between 0 and 100, inclusive.
  • Loop Playback (Boolean) - If Yes, loop the music, repeating it indefinitely.
  • Loop Interval (Floating Point Numbers) - Amount of silence before looping the music. Unit is seconds.
  • Playback Speed (Floating Point Numbers) - Speed to play the music at. 1.0 means default speed. Must be between 0.5 and 2.0, inclusive.
  • Enable Fade In/Out (Boolean) - If Yes, fade the music in and out. See notes for details.

Usage

Miliastra stages can play various built-in Genshin music for players. The music can be browsed from Manage Background Music menu. Background music can be set here, and that will play the music for all players when the stage starts without using any node graphs.

Use this node to play music from node graph. Available music can be browsed here.

Use Player Plays One-Shot 2D Sound Effect or Add Sound Effect Player to play a sound effect instead.

Example

In this example, the music with ID 10130 (Die Mittsommernacht-Fantasie) starts playing for the player when the tab is selected by the player. It plays the section starting from 3:00 (180 seconds from start) to 3:10 (190 seconds from start), at volume 50 (half the amplitude, i.e. ~6dB softer than full gain). It loops the section with 3 second silence between the loops. The music is played at the normal speed. The music fades in at the beginning of the section and fades out at the end of the section. The fade is linear. In this particular example, the fade-in took 5 seconds and the fade-out took 2 seconds (see notes for more detail on fade duration).

Notes

  • If this node cannot run due to any of the problems listed below, it will not cause any side effect. Any music that is already playing will continue to play.
  • Background Music Index can be selected by clicking on the magnifier icon on the right. Clicking the play button plays the music for preview.
  • If Target Entity is not a player entity, this node raises "Entity does not exist" error (can be misleading because the entity may exist).
  • If Background Music Index is not an ID for a music, this node is no-op.
  • If Start Time is negative, this node is no-op.
  • If End Time exceeds the music duration, this value is clamped to the music duration.
  • If Start Time is greater than End Time, this node is no-op. If the two values are equal, this node runs (with Enable Fade In/Out set to Yes, it will even play a bit of music).
  • If Volume is negative or if it exceeds 100, this node is no-op.
  • Because Volume scales the amplitude linearly, it does not scale linearly with human perception, which is logarithmic. If you are making a volume slider, you may want to account for this. See Adjust Player Background Music Volume for an example.
  • If Loop Playback is Yes and Loop Interval is negative, this node is no-op. If Loop Playback is No, Loop Interval can be any value.
  • Loop Interval is not scaled by Playback Speed. For example, if Loop Interval is 3 and Playback Speed is 1.5, the loop interval will take 3 seconds.
  • Playback Speed is less than 0.5 or greater than 2.0, this node is no-op.
  • Unlike sound effects, Playback Speed does not apply pitch correction. Faster speed means the music plays at higher pitch.
  • Fade in/out is linear on amplitude. The fade-out seems to always take two seconds, but fade-in seems to vary in time, ranging from 2 to 5 seconds. This needs more testing.
  • If Enable Fade In/Out is set to Yes and the part of the music played is short, It can increase the duration of the played part of the music. This needs more testing.
  • Enable Fade In/Out behaves strangely with Playback Speed. It can increase the duration of the played part of the music. This needs more testing.
  • Background music may continue to play during loading out of the game. You may want to stop the music before settling the stage.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
