Set Creation Disruptor Device

This documentation was published soon after the release of this node. Some of the information may be inaccurate. Let me know if you find something wrong.

This server node is only available in Beyond Mode.

Sets creation disruptor device.

Input Parameters

  • Target Entity (Entity) - Entity that has a creation disruptor device component.
  • Device ID (Integer) - ID for the creation disruptor device. e.g. 1

Usage

v7.2 introduced creation disruptor device, which is a component that can apply physical forces to creations. It's similar to character disruptor device, but it works on creations.

Use this node to switch the active creation disruptor device. Only one creation disruptor device at a time can be active on an entity.

Example

In this example, we enable the creation disruptor device 1 when the tab is selected.

Notes

  • If Target Entity is not an existing entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have a creation disruptor device component, this node raises "Entity component does not exist" error.
  • If Device ID is not an ID for a creation disruptor device, all creation disruptor device on this entity is disabled.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
