When All Player's Characters Are Revived

Triggers when all characters are revived for a player.

Output Values

  • Player Entity (Entity) - Player entity that has the revived characters.

Usage

Use this node to listen to the event when all characters are revived for a player. This node must be mounted on the player entity. Consider using When Character Revives instead.

Notes

  • This node is triggered when the revive initiates as the loading screen starts to show, not when the loading screen goes away.
  • Revive Character does not trigger this node, but Revive All Player's Characters does trigger this node.
  • Abnormal downing (drowning and falling) does not trigger this node. Use When Player Is Abnormally Downed and Revives to listen to this event.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
