Switch Active Text Bubble

Activates a text bubble.

Input Parameters

  • Target Entity (Entity) - Entity with a text bubble component.
  • Text Bubble Configuration ID (Config ID) - ID for the text bubble. e.g. 1

Usage

Text bubble can be used to show text at an entity. It can be configured in text bubble component, which can be mounted on object, creation, and character entities.

Use this node to activate a text bubble. Only one text bubble can be active at a time on an entity. So if this entity already has an active text bubble when this node is used, the new text bubble will replace the old one.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Target Entity does not have the text bubble component, this node raises "Entity component does not exist" error.
  • If Text Bubble Configuration ID is not an ID of a text bubble, any active text bubble on the entity is deactivated.

Performance

This node took ~3 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
