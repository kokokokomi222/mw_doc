Deactivate Revive Point

Deactivates a revive point.

Input Parameters

  • Player Entity (Entity) - Player entity to deactivate the revive point for.
  • Revive Point ID (Integer) - ID of the revive point to deactivate.

Usage

When all characters of a player are down, the player can revive at revive points. Revive points can be configured in stage setting. The list of active revive points for players can be configured in player template details panel. Use this node to deactivate a revive point for a player.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading.
  • If Revive Point ID is not an ID of a revive point, this node is no-op.
  • If this node runs while the player is in the revive screen, the revive point is invalid for the player's revival from this revive screen.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
