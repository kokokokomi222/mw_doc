Switch Combat Text Filter Template

This documentation was published soon after the release of this node. Some of the information may be inaccurate. Let me know if you find something wrong.

Switches combat text filter template.

Input Parameters

  • Player Entity (Entity) - Player entity to switch the combat text filter template for.
  • Combat Text Template ID (Integer) - ID for the combat text filter template, as defined in the component. e.g. 1

Usage

v7.2 introduced combat text filter, giving craftspeople ability to hide or adjust the size of combat texts.

Combat text filter can be configured in Combat Text Prompt Filter component for players.

Use this node to switch player's combat text filter to a different template.

Note that even though this node is available in classic mode, Combat Text Prompt Filter component does not exist on classic mode. Thus, it cannot perform any meaningful function in classic mode.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity does not have a Combat Text Prompt Filter component, this node raises "Entity component does not exist" error.
  • If Combat Text Template ID is 0, the player gets its combat text prompt filter disabled, reverting to the default text size and display. If Combat Text Template ID is not an ID for a combat text template and is not 0, this node is no-op.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
