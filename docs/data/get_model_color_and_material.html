Get Model Color & Material

Get custom color and material of the entity.

Input Parameters

  • Target Entity (Entity) - Entity to get the custom color and material from. Must be an object entity.

Output Values

  • Enable Custom Color? (Boolean) - Yes if the custom color is enabled, No otherwise
  • Color Blend Mode (Blend Mode Enum) - One of Override or Multiply
  • Color (Integer) - The custom color. 0xRRGGBB where RR is the red, GG is the green, and BB is the blue component of the color in hexadecimal. e.g. 16776960 for yellow.
  • Color Opacity (Floating Point Number) - The opacity of the custom color. Between 0 and 100, inclusive.
  • Enable Custom Material? (Boolean) - Yes if the custom material is enabled, No otherwise
  • Material (Material Enum) - One of Freeze or Petrification

Usage

Luna VIII introduced custom color and material for entities. With this feature, models can be put into different colors. This node lets you get these custom color and material values in the node graph.

Example

In this example, we get the custom color of the entity and print the red, green, and blue component of the color. Highest byte (bit 16 to 23) encodes red component of the color, next byte (bit 8 to 15) encodes green, and last byte (bit 0 to 7) encodes blue.

Notes

  • Target Entity must be an object entity. If Target Entity is a stage, character, player, or creation entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • If Enable Custom Color? is No, the values of Color Blend Mode, Color, Color Opacity are not meaningful.
  • If Enable Custom Material? is No, the value of Material is not meaningful.
  • If custom color is set to a color code that is out or range (negative, or at least 2^24) by Edit Model Color & Material, this node returns that out-of-range number. Thus, there is no guarantee that Color is between 0 and 2^24-1.
  • When Color Blend Mode is Override, it appears to use the following blending written in pseudo-shader code: output.rgb = original.rgb * (1.0-opacity/100.0) + custom_color.rgb * opacity/100.0. If the opacity is full at 100.0, the model appears to be painted uniformly by the custom color. Below is an example of a model painted blue at full opacity with Override blend mode.
  • When Color Blend Mode is Multiply, it appears to use the following blending written in pseudo-shader code: output.rgb = original.rgb * (1.0-opacity/100.0) + original.rgb * custom_color.rgb * opacity/100.0. If the opacity is full at 100.0, the model appears to be in custom color, but the darker parts of the original texture is kept dark. Below is an example of a model painted blue at full opacity with Multiply blend mode.
  • Material seems to be applied after the custom color is applied.
  • Models with Freeze and Petrification custom material appears like the below example.
  • Custom color and material on decorations cannot be accessed or modified by node graphs.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
