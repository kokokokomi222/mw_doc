Add Uniform Basic Linear Motion Device

Start a basic motion device with uniform linear motion.

Input Parameters

  • Target Entity (Entity) - Entity with basic motion device component
  • Motion Device Name (String) - Name of the motion device to assign
  • Motion Device Duration (Floating Point Numbers) - The duration for which this motion device remains active. Unit is in seconds.
  • Velocity Vector (3D Vector) - Velocity of the motion

Usage

Basic motion device with uniform linear motion is typically configured in the component, where the duration and velocity can be specified. However, this node can create a basic motion device with uniform linear motion dynamically, specifying the duration and velocity on runtime. After this node executes, the newly created basic motion device starts running immediately, without having to run Activate Basic Motion Device.

Example

In this example, when tab is selected, the entity will start moving with velocity of (5, 0, 0) for 3 seconds, ending up at 15 meters forward in X direction when it stops. Note that Activate Basic Motion Device was not needed to start moving.

Notes

  • If Target Entity does not have the basic motion device component, this node raises "Entity component does not exist" error.
  • Get Entity Location and Rotation reports the correct intermediate location during this motion, unlike follow motion device or projectile motion device.
  • If there is already a running basic motion device on this entity named Motion Device Name, this node stops that device in the middle of the motion. However, this does not overwrite the basic motion device statically defined in the component. Below example illustrates this issue. We have a statically defined basic motion device with uniform linear motion that moves forward at 2 meters per second for 3 second. In the node graph, we start that statically defined basic motion device. But one second later, we start a dynamically defined basic motion device that moves sideways at 2 meters per second for 3 second. Lastly one more second later, we start the statically defined basic motion device again. All these devices have the same name: my_motion. Say the entity starts at (0, 0, 0). In this scenario, the entity moves forward 2 meters in the first second, ending up at (2, 0, 0). Then this node stops that movement and moves sideways 2 meters in the next second, ending up at (2, 0, 2). And finally, the original statically defined basic motion device gets started again, moving forward for 3 seconds. Thus, the entity comes to rest at (8, 0, 2).

    This behavior is complicated to understand, so we recommend not using duplicate names and explicitly use Stop and Delete Basic Motion Device instead.

Performance

This node took ~16 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
