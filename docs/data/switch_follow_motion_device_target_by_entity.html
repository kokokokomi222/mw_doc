Switch Follow Motion Device Target by Entity

Sets a follow target of the follow motion device.

Input Parameters

  • Target Entity (Entity) - Following entity with a follow motion device component.
  • Follow Target Entity (Entity) - Entity to follow.
  • Follow Target Attachment Point Name (String) - Name of the attachment point of the follow target entity. e.g. GI_RootNode
  • Location Offset (3D Vector) - Location offset. Coordinate system depends on the follow coordinate system below.
  • Rotation Offset (3D Vector) - Rotation offset. Coordinate system depends on the follow coordinate system below.
  • Follow Coordinate System (Enumeration) - One of Relative Coordinate System or World Coordinate System
  • Follow Type (Enumeration) - One of Completely Follow, Follow Location, or Follow Rotation.

Usage

Follow motion device can be used to make an entity follow another entity. It can be configured in the follow motion device component.

Use this node to set the follow target entity. You may want to use Switch Follow Motion Device Target by GUID instead, which works very similarly.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Target Entity does not have the follow motion device component, this node raises "Entity component does not exist" error.
  • If the follow motion device of Target Entity is currently deactivated, this node is no-op.
  • If Follow Target Entity does not exist, the entity will stop following any entity.
  • Follow Target Entity can be the stage entity, although the stage doesn't move, so this behavior is not useful.
  • If Follow Target Entity is a player entity, the entity will follow the active character of the player. Follow Target Attachment Point Name should be an attachment point for the character. If the follow target entity is queried using Get Follow Motion Device Target, it returns the player entity.
  • If Follow Target Attachment Point Name is not a name of an attachment point of Follow Target Entity, it defaults to GI_RootNode.
  • If Follow Coordinate System is Relative Coordinate System, Location Offset and Rotation Offset are in Follow Target Entity's coordinate system. It will be transformed by the follow target entity's rotation, but not entity's zoom.
  • If Follow Coordinate System is Relative Coordinate System, Location Offset and Rotation Offset are in stage coordinate system. It will not be transformed by the follow target entity's rotation or zoom.

Performance

This node took ~7 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
