Activate Fixed-Point Motion Device

Start a basic motion device with fixed-point motion.

Input Parameters

  • Target Entity (Entity) - Entity with basic motion device component
  • Motion Device Name (String) - Name of the motion device to assign
  • Movement Mode (Enumeration) - One of Instant Movement or Uniform Linear Motion
  • Movement SPD (Floating Point Numbers) - Speed of the motion. Unit is in meter per seconds. "Movement Mode" must be Uniform Linear Motion and "Parameter Type" must be Fixed Speed for this argument to take effect.
  • Target Location (3D Vector) - Target Location. This is in world coordinate space, and is not relative to the current location of the entity.
  • Target Rotation (3D Vector) - Target rotation. This is in world coordinate space, and is not relative to the current rotation of the entity. "Lock Rotation" must be No for this argument to take effect.
  • Lock Rotation (Boolean) - If Yes, the entity keeps its original rotation during the motion. If No, the entity continuously rotates toward "Target Rotation" during the motion.
  • Parameter Type (Enumeration) - One of Fixed Speed or Fixed Time. "Movement Mode" must be Uniform Linear Motion for this argument to take effect.
  • Movement Time (Floating Point Numbers) - Duration of the motion. Unit is in seconds. "Movement Mode" must be Uniform Linear Motion and "Parameter Type" must be Fixed Time for this argument to take effect.

Usage

Basic motion device with fixed-point motion is typically configured in the component, However, this node can create a basic motion device with fixed-point motion dynamically. After this node executes, the newly created basic motion device starts running immediately, without having to run Activate Basic Motion Device.

This node has three different modes of operation:

  1. Movement Mode is Instant Movement. In this case, Parameter Type is ignored. The entity teleports to the Target Location immediately.
  2. Movement Mode is Uniform Linear Motion and Parameter Type is Fixed Speed. The entity moves toward Target Location, moving at the speed of Movement SPD meters per second.
  3. Movement Mode is Uniform Linear Motion and Parameter Type is Fixed Time. The entity moves toward Target Location, taking Movement Time seconds to finish.

In all these modes, the entity also turns toward Target Rotation if Lock Rotation is No, working similarly as Add Target-Oriented Rotation-Based Motion Device. If Lock Rotation is Yes, the entity will keep the initial rotation during the motion.

The Target Location is in the world coordinate space, not relative to the current location of the entity. For example, if the current location of the entity is (2, 0, 0), and Target Location is (5, 0, 0), the resulting motion is 3 meters translation, not 5 meters.

The Target Rotation is in the world coordinate space, not relative to the current rotation of the entity. For example, if the current rotation of the entity is (0, 45, 0), and Target Rotation is (0, 180, 0), the resulting motion is 135 degrees rotation, not 180 degrees.

Notes

  • This node is inconsistently named. Other equivalent nodes start with "Add", but this node start with "Activate".
  • If Target Entity does not have the basic motion device component, this node raises "Entity component does not exist" error.
  • Get Entity Location and Rotation reports the correct intermediate location and rotation during this motion, unlike follow motion device or projectile motion device.
  • If there is already a running basic motion device on this entity named Motion Device Name, this node stops that device in the middle of the motion. However, this does not overwrite the basic motion device statically defined in the component. See examples in the notes of Add Uniform Basic Linear Motion Device and Add Uniform Basic Rotation-Based Motion Device for more detail.

    This behavior is complicated to understand, so we recommend not using duplicate names and explicitly use Stop and Delete Basic Motion Device instead.

Performance

This node took ~32 units to run on average, but it seems to have high variance.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
