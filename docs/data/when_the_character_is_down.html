When the Character Is Down

Triggers when a character is downed.

Output Values

  • Character Entity (Entity) - Character entity that was downed.
  • Reason (Enumeration) - One of Node Graph Triggered, Normal Defeat, or Abnormal Defeat
  • Knockdown Entity (Entity) - If normally defeated, entity that dealt the fatal damage. 0 otherwise.

Usage

Use this node to listen to the event when the character is downed. This can occur in multiple ways:

  • HP reaching 0 from damage (Normal Defeat).
  • Using Lose HP on the character (Node Graph Triggered).
  • Using Destroy Entity on the character (Node Graph Triggered).
  • Using Defeat All Player's Characters on the character (Node Graph Triggered).
  • Drowning by running out of stamina while swimming (Abnormal Defeat).
  • Falling too far down the stage (Abnormal Defeat).

This node must be mounted on the character entity. Consider using When All Player's Characters Are Down instead.

Notes

  • This node is triggered as the death animation begins.

Performance

This node took ~5 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
