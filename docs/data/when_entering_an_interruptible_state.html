When Entering an Interrupt-Vulnerable State

This server node is only available in Beyond Mode.

Triggers when entity's poise breaks.

Output Values

  • Event Source Entity (Entity) - Entity that had its poise broken and entered interruption-vulnerable state.
  • Event Source GUID (GUID) - GUID of the above entity. 0 if it was dynamically created.
  • Attacker (Entity) - Entity that dealt the attack that caused the poise break.

Usage

Each character and creation entity has a bar for interruption (known as "poise bar" in Genshin community), which work similarly as HP bar, but for interruption. Poise bar determines how much poise damage the entity can take before the poise breaks and enters interrupt-vulnerable state for staggering.

Maximum interruption bar is 100 for characters and typically ranges from 30 to 2000 for creations. Object entity does not have a poise bar and cannot break poise. Interrupt value (known as "poise damage" in Genshin community) can be configured in the ability unit for objects, or character skill client nodes for skills. Interruption resistance can reduce the poise damage taken by the poise bar.

When the poise break, it can stagger the entity. The effect of stagger depends on the attack. This effect can be configured under "On-hit performance" in ability unit component. It can also interrupt when characters or creations are casting skills. See Interruption Resistance for details on the poise mechanism.

Use this node to listen to the event when the entity is interrupted. Use Get Creation Attribute or Get Character Attribute to query values about interruption.

Notes

  • This node was renamed from "When Entering an Interruptible State" to "When Entering an Interrupt-Vulnerable State".
  • Event Source Entity and Event Source GUID may not be the same as the self entity, if it was forwarded by Forwarding Event.
  • If "Current Interruption Status" of Event Source Entity is queried from Get Creation Attribute or Get Character Attribute during this event, it returns Interrupt-Vulnerable State.
  • If the poise break was caused by a transformative reaction (e.g. overloaded, electro-charged), then Attacker is the entity that initiated the reaction.

Performance

This node took ~5 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
