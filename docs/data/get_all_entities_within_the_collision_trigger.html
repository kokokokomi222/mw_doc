Get All Entities Within the Collision Trigger

Gets the list of entities in the collision trigger.

Input Parameters

  • Target Entity (Entity) - Entity that has the collision trigger component.
  • Trigger ID (Integer) - ID of the collision trigger. e.g. 1

Output Values

  • Entity List (Entity List) - List of the entities in the collision trigger.

Usage

Collision triggers are used to detect whether an entity is within certain geometry. Collision triggers can be configured in the collision trigger component.

Use this node to get all entities that is colliding with the collision trigger.

Notes

  • Collision triggers can be configured to only trigger with specified type of entities (characters, objects, and/or creations). If an entity is not one of the specified type, this node will not include it in its return value.
  • Characters and creations have their inherent collision trigger source geometry, so nothing needs to be configured on characters and creations to be included in this function's return value. However, one needs to add collision trigger source component for object entities to be included in this function's return value. Characters and creations can also add additional collision trigger source component.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
