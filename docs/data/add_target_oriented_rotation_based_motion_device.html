Add Target-Oriented Rotation-Based Motion Device

Start a basic motion device that rotate towards a target rotation.

Input Parameters

  • Target Entity (Entity) - Entity with basic motion device component
  • Motion Device Name (String) - Name of the motion device to assign
  • Motion Device Duration (Floating Point Numbers) - The duration for which this motion device remains active. Unit is in seconds.
  • Target Angle (3D Vector) - Target rotation. This is in world coordinate space, and is not relative to the current rotation of the entity.

Usage

Basic motion device that rotate towards target is typically configured in the component, where the duration and the target rotation can be specified. However, this node can create a basic motion device that rotate towards target dynamically, specifying the duration and the target rotation on runtime. After this node executes, the newly created basic motion device starts running immediately, without having to run Activate Basic Motion Device.

The Target Angle is in the world coordinate space, not relative to the current rotation of the entity. For example, if the current rotation of the entity is (0, 45, 0), and Target Angle is (0, 180, 0), the resulting motion is 135 degrees rotation, not 180 degrees.

The motion follows spherical linear interpolation, often shortened as slerp, to achieve smooth transition from one rotation to another.

Example

In this example, when tab is selected, the entity will start turning toward the character that selected the tab for 2 seconds, ending up facing the character when it stops. Note that Activate Basic Motion Device was not needed to start moving.

Notes

  • Target Angle is more appropriately named "Target Rotation" as in Activate Fixed-Point Motion Device.
  • If Target Entity does not have the basic motion device component, this node raises "Entity component does not exist" error.
  • Get Entity Location and Rotation reports the correct intermediate rotation during this motion, unlike follow motion device or projectile motion device.
  • If there is already a running basic motion device on this entity named Motion Device Name, this node stops that device in the middle of the motion. However, this does not overwrite the basic motion device statically defined in the component. See examples in the notes of Add Uniform Basic Linear Motion Device and Add Uniform Basic Rotation-Based Motion Device for more detail.

    This behavior is complicated to understand, so we recommend not using duplicate names and explicitly use Stop and Delete Basic Motion Device instead.
