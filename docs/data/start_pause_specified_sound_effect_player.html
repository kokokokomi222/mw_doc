Start/Pause Specified Sound Effect Player

Pause or resume a looping sound effect player.

Input Parameters

  • Target Entity (Entity) -Entity that has the looping sound effect player.
  • SFX Player ID (Integer) - ID of the looping sound effect player.
  • Recover (Boolean) - If No, pause the sound. If Yes, resume the sound.

Usage

Use this node to pause or resume a looping sound effect played by Add Sound Effect Player.

SFX Player ID can be obtained from Add Sound Effect Player.

Notes

  • If Target Entity is not an entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have the Sound Effect Player component, this node raises "Entity component does not exist" error.
  • If SFX Player ID is not an ID for a currently playing looping sound effect, this node is no-op.
  • If Recover is Yes and the sound is already playing, this node is no-op. If Recover is No and the sound is already paused, this node is no-op.
  • If the sound is paused during loop interval silence, it accounts for the duration of the interval correctly. For example, if the loop interval is set to 5 seconds, this node pauses the sound 2 seconds into the loop interval silence, and this node resumes the sound later, then the silence continues for 3 more seconds before starting the sound.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
