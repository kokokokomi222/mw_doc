Activate/Disable Collision Trigger Source

Enables/disables collision trigger source.

Input Parameters

  • Target Entity (Entity) - Entity that has a collision trigger source.
  • Activate (Boolean) -If Yes, collision trigger source is enabled. If No, it is disabled.

Usage

Collision triggers are used to detect whether an entity is within certain geometry. Collision triggers can be configured in the collision trigger component.

Collision trigger source component can be added to object/character/creation entities, giving the entity additional geometry to collide with collision triggers. Use this node to either enable or disable collision trigger source.

  • If Target Entity does not exist, this node raises "Entity does not exist" error.
