When Character Revives

Triggers when a character revives.

Output Values

  • Character Entity (Entity) - Character entity that revived.

Usage

Use this node to listen to the event when the character is revived. This node must be mounted on the character entity. Consider using When All Player's Characters Are Revived instead.

Example

In this example, we show a text bubble on the character that is revived.

Notes

  • This node is triggered when the revive initiates as the loading screen starts to show, not when the loading screen goes away.
  • Revive Character and Revive All Player's Characters triggers this node.
  • Abnormal downing (drowning and falling) triggers this node.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
