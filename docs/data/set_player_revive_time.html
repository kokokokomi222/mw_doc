Set Player Revive Time

Sets the revive duration for a player.

Input Parameters

  • Player Entity (Entity) - Player entity to set the revive duration for.
  • Duration (Integer) - Revive duration. Unit is seconds.

Usage

Revive duration can be configured for players in player template detail panel. When player is in the revive screen, the timer will count down for this duration and the player can revive back to field only after the timer reaches zero.

Use this node to set the revive duration of a player.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading.
  • If Duration is not positive, this node is no-op.
  • If the player is currently in a revive screen, this node does not affect the current revival timer.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
