Query Player Class Level

This server node is only available in Beyond Mode.

Gets player's class level.

Input Parameters

  • Player Entity (Entity) - Player entity to get the level for.
  • Class Config ID (Config ID) - ID of the class. e.g. 1090519041

Output Values

  • Level (Integer) - Player's class level.

Usage

Use this node to get player's class level. Note that each class has its own level.

Example

In this example, we increase the player's class level by one when the tab is selected.

Notes

  • If Target Player does not exist, this node raises "Entity does not exist" error and returns 0.
  • If Target Player is not a player entity, this node returns 0.
  • If Class Config ID is not an ID of a class, this node returns 0.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
