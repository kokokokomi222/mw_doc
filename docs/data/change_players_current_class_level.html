Change Player's Current Class Level

This server node is only available in Beyond Mode.

Changes player's class level.

Input Parameters

  • Target Player (Entity) - Player entity to change the class level for.
  • Level (Integer) - New level. Must be between 1 and maximum level of the class, inclusive.

Usage

Use this node to change the level of player's class. Note that each class has its own level, so the level may change if the class is changed using Change Player Class. The maximum class level can be configured in the class details panel.

You may want to use Increase Player's Current Class EXP instead.

Notes

  • If Target Player does not exist, this node raises "Entity does not exist" error.
  • If Target Player is not a player entity, this node is no-op.
  • If Level is less than 1 or greater than the class maximum level, this node is no-op.
  • If this node successfully runs, class EXP is set to 0. If this node fails, the current EXP does not change.
  • If the changed level is same as the previous level, then When Player Class Level Changes does not trigger.
  • Class maximum level can be configured to an integer between 1 and 200, inclusive.
  • If the level increases from previous level, a yellow effect is played on the character, quickly followed by a blue effect with level number on the head. If level increases multiple times quickly, all the yellow effects are played together right away, but the blue effects are put on a queue and plays one at a time. If the level stays the same or decreases, no effect is played.

Performance

This node took ~30 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
