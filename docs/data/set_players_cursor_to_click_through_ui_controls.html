Set Player's Cursor to Click Through UI Controls

This server node is only available in Beyond Mode.

Sets whether cursor can click through UI controls.

Input Parameters

  • Player Entity (Entity) - Entity of the player to set the cursor click-through for.
  • Click Through UI Controls? (Boolean) - Yes to let cursor collision work through all UI controls. No otherwise.

Usage

Luna VIII introduced various features involving cursors. Cursor settings can be configured in the player detail panel. "Allow UI control click-through" can be set to Yes in order to make the cursor collisions to work even when a UI control is blocking it. This node lets you toggle this setting dynamically.

Note that this node does not affect UI controls that does not collide with cursor. See the note below for detail.

Notes

  • If Player Entity is not a player entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • Not all UI controls block cursor collisions. If the UI controls are not clickable (like text boxes or images), the UI controls allow cursor collisions through even when Click Through UI Controls? is set to No. This node only affects cursor collisions blocked by UI controls that are clickable, like interactive button, custom button, custom switch, item display, etc.

Performance

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
