When Text Bubble Is Completed

Triggers when text bubble is completed.

Output Values

  • Bubble Owner Entity (Entity) - Entity with a text bubble component.
  • Character Entity (Entity) - Character entity that can see the text bubble.
  • Text Bubble Configuration ID (Config ID) - ID of the currently active text bubble.
  • Text Bubble Completion Count (Integer) - Number of times the character have seen this text bubble completed.

Usage

Text bubble can be used to show text at an entity. It can be configured in text bubble component, which can be mounted on object, creation, and character entities.

Use this node to listen to the event when a text bubble completes. This node must be mounted on the entity that has the text bubble component. It is important that "Send end event?" is set to Yes. If not, this node will not be triggered.

Notes

  • "Send end event?" must be set to Yes on the component to trigger this event.
  • If the text bubble is configured to loop, this node will trigger every time the loop ends.
  • If the text bubble contains multiple texts, this node only triggers when the last text completes.
  • If the text bubble is switched to other text bubble by Switch Active Text Bubble (or deactivated by the node), this node does not trigger.
  • If no character is within the visible radius of the entity, this node does not trigger. This radius is centered at the root of the entity, not the attachment point of the text bubble.
  • If there are multiple characters within the visible radius of the entity, this node is triggered once for each character. The value Text Bubble Completion Count is tracked separately for each player. Even if a player switches to another character in classic mode, Text Bubble Completion Count will be the total time seen by the player, not the character.
  • If the text bubble is set to be initially effective, this node reports different Text Bubble Configuration ID then expected. This initial text bubble is also considered separate for the purpose of counting Text Bubble Completion Count.
  • If the entity is destroyed and created again, Text Bubble Completion Count counts are reset.

Performance

This node took ~6 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
