Query If Dictionary Contains Specific Value

Returns whether the value is in the dictionary.

Input Parameters

  • Dictionary (Generic) - Dictionary to test
  • Value (Generic) - Potential value of the dictionary

Output Values

  • Include (Boolean) - Yes if the value is in the dictionary. No otherwise.

Usage

Use this node to test whether a value is in the dictionary.

Example

In this example, we have a node graph variable dictionary named archon_to_element. We test whether "Hydro" is a value in the dictionary, printing "There is a hydro archon." if true, printing "There is no hydro archon." if false,

Notes

  • Changing the type of Dictionary will change the type of Value to match it, and vice versa.
  • If the type of Value is floating point number or 3D Vector, the node uses approximate equal as defined in Equal. For example, if Dictionary is {"test": 999.9999} and Value is 1000, this node returns Yes because 999.9999 is approximately equal to 1000.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~11 units on average. For a dictionary with 100 key-value pairs, this node took ~80 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
