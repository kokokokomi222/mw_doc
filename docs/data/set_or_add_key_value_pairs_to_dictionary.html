Set or Add Key Value Pairs to Dictionary

Add or modify a key-value pair of a dictionary.

Input Parameters

  • Dictionary (Generic) - Dictionary to modify
  • Key (Generic) - Key for the dictionary
  • Value (Generic) - New value to set

Usage

Use this node to add a new key-value pair to a dictionary, or modify a value for an existing key-value pair in a dictionary.

Example

In this example, we have a node graph variable dictionary named round_score which stores key-value pair of player entity and player's score. When a player selects the tab, we get the current score of the player from the dictionary using Query Dictionary Value by Key, then set the new score of the player by adding 100.

Notes

  • Changing the type of Dictionary will change the type of Key and/or Value to match it, and vice versa.
  • If Key does not exist in Dictionary and Dictionary has at least 1001 key-value pairs, this node is no-op. Curiously, it functions properly when Dictionary has exactly 1000 key-value pairs.
  • If Key or Value is left empty, it is considered to be the default value of that type.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~14 units on average. For a dictionary with 100 key-value pairs, this node took ~110 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
