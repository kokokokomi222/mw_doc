Query Player's Followed Control Motion Device

This server node is only available in Beyond Mode.

Gets the control motion device followed by a player.

Input Parameters

  • Player Entity (Entity) - Player entity

Output Values

  • Control Motion Device Entity (Entity) - Control motion device entity that is followed by the player. Default entity 0 if the player is not following any control motion device.

Usage

Luna VIII introduced control motion devices. An entity can have a control motion device component, then this entity's movement can be controlled directly by players instead of controlling Manekin/Manekina. This feature can be used to create a vehicle that can be driven by players.

This node lets you query the control motion device entity that is followed by the player.

Example

We have a node graph mounted on a player. If an interactive button is pressed by the player, we get the followed control motion device entity and apply a unit status to buff the speed of the entity.

Notes

  • Player Entity must be a player entity. If Player Entity is a stage, character, object, or creation entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • If no control motion device entity is being followed the player, this node returns the default entity, 0.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
