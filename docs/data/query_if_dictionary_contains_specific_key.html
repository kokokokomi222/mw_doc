Query If Dictionary Contains Specific Key

Returns whether the key is in the dictionary.

Input Parameters

  • Dictionary (Generic) - Dictionary to test
  • Key (Generic) - Potential key of the dictionary

Output Values

  • Include (Boolean) - Yes if the key is in the dictionary. No otherwise.

Usage

Use this node to check whether a key is in the dictionary.

Notes

  • Changing the type of Dictionary will change the type of Key to match it, and vice versa.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~11 units on average. For a dictionary with 100 key-value pairs, this node took ~80 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
