Mount Looping Special Effect

Mount a looping effect on an entity.

Input Parameters

  • Special Effects Asset (Config ID) - ID of the looping effect to mount. e.g. 10001103
  • Target Entity (Entity) - Entity to play the effect at.
  • Attachment Point Name (String) - Name of the attachment point. e.g. "GI_RootNode"
  • Move With the Target (Boolean) - If Yes, the effect will follow the entity. If No, the effect will remain where it started playing.
  • Rotate With the Target (Boolean) - If Yes, the effect will rotate with the entity. If No, the effect's rotation will remain fixed.
  • Location Offset (3D Vector) - Offset relative to the entity's attachment point. This transformation is in the entity coordinate space, taking entity transform into consideration.
  • Rotation Offset (3D Vector) - Rotation relative to the entity's attachment point. This transformation is in the entity coordinate space, taking entity transform into consideration.
  • Zoom Multiplier (Floating Point Numbers) - Zoom multiplier for the effect.
  • Play Built-in Sound Effect (Boolean) - If Yes, the effect will play a built-in sound associated with the effect, if one exists.

Output Values

  • Special Effect Instance ID (Integer) - ID of the instance of the playing looping effect. Use this to clear the looping effect. This value is always non-negative. If a looping effect could not be mounted, this value is 0.

Usage

This node is used to play looping effect, which is a visual special effect that plays continuously on loop until it is cleared by Clear Looping Special Effect. To play timed effect, use Play Timed Effects instead. To play sound effect, use Start/Pause Specified Sound Effect Player or Player Plays One-Shot 2D Sound Effect instead.

Effects may not be visible when you preview them for various reasons. Some effects are too small or too large to be seen. Some effects must be placed near ground for it to be visible, while some others must move in order to be visible. Some effects also come with built-in sound with can be played with Play Built-In Sound Effect. See the looping effect browser for details on each lopping effect.

The effect can be stopped with Clear Looping Special Effect or Clear Special Effects Based on Special Effect Assets.

Notes

  • Special Effects Asset can be selected by clicking on the magnifier icon on the right. Clicking the play button plays the effect on stage (although it may be difficult to see for some effects).
  • If Special Effects Asset is not an ID for a looping effect, this node is no-op.
  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Target Entity does not have the "VFX Playing" component, this node raises "Entity component does not exist" error.
  • If Target Entity has model visibility turned off from the entity details panel or Activate/Disable Model Display, the timed effect does not show.
  • If Attachment Point Name is not a name for an attachment point of the entity, this node raises "Entity component does not exist" error, which is misleading.
  • The position of the looping timed effect uses the entity coordinate system. Any offset specified with Location Offset or Rotation Offset takes effect after entity transformation is applied.
  • If entity is destroyed while the effect is playing, The effect stops playing.
  • One entity can have at most 10 looping effects playing at once. Note that this count does not include timed effects. If this node is used while 10 effects are already playing, this node is no-op and returns 0.
  • Not all parts of the effect may scale by Zoom Multiplier. Some parts may even be visible even when Zoom Multiplier is 0 or negative.
  • Appearance of effects can depend on camera location.
  • Most looping effects have entering animation.

Performance

This node took ~10 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
