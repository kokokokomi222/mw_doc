Recover Basic Motion Device

Resume a paused basic motion device.

Input Parameters

  • Target Entity (Entity) - Entity with a paused basic motion device
  • Motion Device Name (String) - Name of the motion device, as specified in the basic motion device component

Usage

See Activate Basic Motion Device for details on basic motion device. This node resumes a basic motion device paused with Pause Basic Motion Device.

Example

In this example, we have a node graph mounted on an entity with basic motion device component. When we receive Time Stop Skill Used signal, we pause the basic motion device named "Move Toward Exit". When we receive Time Stop Skill Ended signal, we resume the basic motion device named "Move Toward Exit".

Notes

  • If Target Entity does not have the basic motion device component, this node raises "Entity component does not exist" error.
  • If there is no paused basic motion device with name Motion Device Name, this node is no-op.

Performance

This node took ~7 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
