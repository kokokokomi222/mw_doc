Activate Basic Motion Device

Start a basic motion device.

Input Parameters

  • Target Entity (Entity) - Entity to start the basic motion device for
  • Motion Device Name (String) - Name of the motion device, as specified in the basic motion device component

Usage

Basic Motion Device is an entity component that let us move dynamic entities. It can be used without any node graph by adding the component in the third tab of the entity detail panel and setting an "Initially Effective" motion device. However, the above method will move the entity at the start of the stage. This node instead lets us dynamically start a basic motion device when we want to.

Despite the name, Follow Motion Device is a completely separate system, and it has nothing to do with Basic Motion Device. See Activate/Disable Follow Motion Device for detail.

Notes

  • If Target Entity does not have the basic motion device component, this node raises "Entity component does not exist" error.
  • If Motion Device Name does not exist in the basic motion device component, this node is no-op.
  • Get Entity Location and Rotation reports the correct intermediate location and rotation during this motion, unlike follow motion device or projectile motion device.
  • Multiple basic motion devices can run at the same time, but the behaviors of every combination of devices would be too complicated to describe.

Performance

This node took ~28 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
