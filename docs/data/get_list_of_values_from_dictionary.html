Get List of Values from Dictionary

Returns the list of values of the dictionary.

Input Parameters

  • Dictionary (Generic) - Dictionary to get the values from

Output Values

  • Value List (Generic) - List of values of the dictionary

Usage

Use this node to get all the values of the dictionary. If you would like to iterate over this list using List Iteration Loop, use a local variable to store the output of this node first, as recommended in the documentation page for List Iteration Loop.

The values in the returned list is not sorted and can be in any order.

Example

In this example, we have a node graph variable dictionary named round_score which stores key-value pair of player entity and player's score. We iterate over all values of the dictionary to print them. There are no guarantees on the order of the values.

Notes

  • Changing the type of Dictionary will change the type of Value List to match it, and vice versa.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~10 units on average. For a dictionary with 100 key-value pairs, this node took ~90 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
