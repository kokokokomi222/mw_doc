When Global Timer Is Triggered

Triggers when countdown global timer reaches zero.

Output Values

  • Event Source Entity (Entity) - Entity that has the global timer.
  • Event Source GUID (GUID) - GUID of above Entity. 0 if the entity was created dynamically.
  • Timer Name (String) - Name of the timer as specified in Timer Management.

Usage

Use this node to listen to the event when a countdown global timer reaches zero. This node does not trigger for stopwatch global timers.

Example

In this example, we listen to when the global timer named Round Timer reaches zero, and print "Round is finished!".

Notes

  • Event Source Entity and Event Source GUID may not be the same as the self entity, if it was forwarded by Forwarding Event.
  • For maintenance of the node graph, it is recommended that Timer Name is always put into Multiple Branches or Equal so it does not unexpectedly trigger on other global timers.
  • In this event, the global timer is considered to be stopped. So getting the time on the global timer using Get Current Global Timer Time will yield 0. Starting the global timer again with Start Global Timer will also work because the global timer does not exist and is not running.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
