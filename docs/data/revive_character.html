Revive Character

This server node is only available in Beyond Mode.

Revives a character.

Input Parameters

  • Character Entity (Entity) - Character entity to revive.

Usage

Use this node to revive a character in beyond mode. This is a different from the typical revive: The character is revived at the location where the character was downed, not at a revive point. It also does not use up revive count.

Consider using Revive All Player's Characters instead if you want to use the usual revive system. In classic mode, use Revive the active character instead.

Notes

  • If Character Entity does not exist, this node raises "Entity does not exist" error.
  • If Character Entity is not a character entity, this node raises "Entity does not exist" error, which is misleading.
  • If Character Entity is not down, this node is no-op.
  • This node successfully revives the character if the character is in a death animation.
  • When successful, The character is revived at the location and rotation where the character was downed, not at a revive point. Camera is moved to look the back of the character.
  • This revive does not decrement the revive count.
  • This revive does not trigger When All Player's Characters Are Revived, but it triggers When Character Revives.

Performance

This node took ~25 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
