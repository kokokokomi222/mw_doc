Set Character Disruptor Device

This server node is only available in Beyond Mode.

Sets character disruptor device.

Input Parameters

  • Target Entity (Entity) - Entity that has a character disruptor device component.
  • Device ID (Integer) - ID for the character disruptor device. e.g. 1

Usage

Character disruptor device is a component that can apply physical forces to characters.

Use this node to switch the active character disruptor device. Only one character disruptor device at a time can be active on an entity.

Example

In this example, we enable the character disruptor device 1 when the tab is selected.

Notes

  • If Target Entity is not an existing entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have a character disruptor device component, this node raises "Entity component does not exist" error.
  • If Device ID is not an ID for a character disruptor device, all character disruptor device on this entity is disabled.

Performance

This node took ~3 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
