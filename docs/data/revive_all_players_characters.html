Revive All Player's Characters

Revives all characters of a player.

Input Parameters

  • Player Entity (Entity) - Player entity to revive the characters for.
  • Deduct Revives (Boolean) - If Yes, reduce the revive count by 1. If No, keep the revive count the same.

Usage

Use this node to revive all characters owned by a player. The character is revived at a revive point. This node does not work if any of the characters are alive. See notes for detail.

Consider using Revive Character instead in beyond mode, if you want to revive the character where they were downed. Consider using Revive the active character instead in classic mode.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading.
  • In beyond mode, this node revives the character owned by the player. In classic mode, this node revives all characters owned by the player only when every character owned by the player is down.
  • This node succeeds even when the player has 0 revives left, regardless of what Deduct Revives is.
  • This node fails to revive the characters if the Player Entity's character is in a death animation.
