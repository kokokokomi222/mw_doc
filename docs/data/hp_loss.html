Lose HP

Decreases HP of an entity.

Input Parameters

  • Target Entity (Entity) - Target entity that loses HP.
  • HP Loss (Floating Point Numbers) - Amount of HP to lose.
  • Lethal (Boolean) - If No, this HP loss does not occur if it would bring the HP to 0 or less.
  • Can be blocked by invincible (Boolean) - If Yes, this node has no effect if the target entity has "Special Status: Invincible" unit status effect.
  • Can be Blocked by Locked HP (Boolean) - If Yes, this node has no effect if the target entity has "Special Status: HP Locked" unit status effect.
  • Damage Pop-Up Type (Enumeration) - One of No Pop-Up, Regular Pop-Up, or CRIT Hit Pop-Up

Usage

Use this node to decrease HP of an entity. If you would like the decrease to be an attack that has initiator, does elemental reactions, and generates attack events, use Initiate Attack instead.

Notes

  • This node has been renamed from "HP Loss" to "Lose HP".
  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Target Entity is a stage or player entity, this node raises "Entity does not exist" error (which can be misleading).
  • If HP Loss is negative, this node is no-op.
  • If Lethal is No and HP Loss is greater or equal to the current HP of Target Entity, this node is no-op.
  • If Target Entity has "Special Status: Invincible" unit status effect and Can be blocked by invincible is Yes, this node is no-op. If Target Entity has "Special Status: Invincible" unit status effect and Can be blocked by invincible is No, the hp loss occurs, but the text pop up does not show.
  • If Target Entity has "Special Status: HP Locked" unit status effect and Can be Blocked by Locked HP is Yes, this node is no-op. If Target Entity has "Special Status: HP Locked" unit status effect and Can be Blocked by Locked HP is No, the hp loss occurs, but the text pop up does not show.
  • If Target Entity has "Special Status: HP Cannot Drop Below Specified Value" unit status effect, the HP loss will not bring it below the configured HP threshold. For example, if Target Entity has 10000 max HP, 6000 current HP, HP threshold configured to 50%, and HP Loss is 2000, then the resulting HP loss is 1000 because the entity cannot go below 5000 HP.
  • If Damage Pop-Up Type is not No Pop-Up, the damage will appear as white text. Text is bigger for CRIT Hit Pop-Up. The displayed HP loss amount is rounded up to an integer (this rounding behavior differs from healing text).

Performance

This node took ~12 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
