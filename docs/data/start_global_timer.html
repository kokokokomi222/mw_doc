Start Global Timer

Starts a global timer.

Input Parameters

  • Target Entity (Entity) - Entity to start the global timer at.
  • Timer Name (String) - Name of the timer as specified in Timer Management.

Usage

First, it's important to distinguish the difference between timers and global timers. They may seem similar, but they are completely separate systems with different purposes. Global timers only fire once, but it can count up or down. Global timer is primarily used to be displayed in UI by being mounted on the stage or a player. Global timer can also be used to precisely measure a span of time. State of a Global timer can be queried by Get Current Global Timer Time.

On the other hand, timer can fire multiple times at specified moments, and it can also repeat on loop. State of a timer cannot be queried from a node graph.

Global timers are often mounted on the stage entity or player entities, because those global timers can then be shown from UI. But global timers can also be displayed through nameplate.

Global timers do not need node graphs to function. It can be configured in Timer Management and then added to the global timer component. This will start the global timer when the entity is created.

Instead of adding to the global timer component, one can use this node to start a global timer from a node graph.

Example

We set up a global timer named Round Timer in the Timer Management as seen above in the usage section. Then, a global timer component is added to the entity, but it is kept empty without attaching any global timers.

Lastly, we start the global timer when Round Start signal is received. This will start a timer that can be viewed from UI or a nameplate.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error and continues execution.
  • If Target Entity does not have the global timer component, this node raises "Entity component does not exist" error and continues execution.
  • If Timer Name is not the name of a global timer defined in Timer Management, this node is no-op.
  • If there is a global timer named Timer Name already running on the entity, this node is no-op.
  • If the entity is destroyed and re-created using Create Entity, the entity does not retain its global timer state from before. If it has a global timer in the component, it will start ticking from the beginning again.
  • If the global timer is queried with Get Current Global Timer Time right after this node in the same node graph, it returns a time close to the starting value of the global timer instead of 0.

Performance

This node took ~7 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
