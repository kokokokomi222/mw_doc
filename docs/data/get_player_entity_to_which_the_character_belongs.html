Get Player Entity to Which the Character Belongs

Gets the player that owns the character.

Input Parameters

  • Character Entity (Entity) - Character entity.

Output Values

  • Affiliated Player Entity (Entity) - Player entity that owns the character.

Usage

Use this node to get the player entity from a character entity. This node is very frequently used in Miliastra. Use Get All Character Entities of Specified Player to get the character entities from a player entity.

Example

In this example, we make a UI control visible for a player when the player selects the tab. Note that Selector Entity from When Tab Is Selected is a character entity, but Set UI Control (Group) Status wants the player entity, so we had to "convert" the character entity to player entity.

Notes

  • If Character Entity does not exist, this node raises "Entity does not exist" error and returns 0.
  • If Character Entity is not a character entity, this node raises "Entity does not exist" error, which is misleading, and returns 0.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
