Increase CD for Specified Skill Instance

This documentation was published soon after the release of this node. Some of the information may be inaccurate. Let me know if you find something wrong.

Modifies cooldown for skill instance.

Input Parameters

  • Target Entity (Entity) - Character entity that has the skill instance.
  • Skill Instance ID (Integer) - ID of the skill instance. e.g. 10000001
  • CD Increase Value (Floating Point Numbers) - Cooldown to set for the skill instance. Unit is seconds.
  • Limit Maximum CD Time (Boolean) - If Yes, the resulting cooldown is clamped to the cooldown of the skill.

Usage

This node, introduced in v7.2, allows us to modify the cooldown for the specific skill instance.

To modify the cooldown for the skill that is active on the skill slot, use Increase Character Skill CD instead.

Example

In this example, we have an entity with two tabs. If the first tab is selected, we add a skill instance to the skill slot Skill1: E and store the skill instance to a node variable. If the second tab is selected, we increase the cooldown of that skill instance to 5.

Notes

  • If Target Entity is not an existing entity, this node raises "Entity does not exist" error.
  • If Target Entity is not a character entity, this node raises "Entity component does not exist" error.
  • If Skill Instance ID is not an ID for a skill instance, this node is no-op.
  • If CD is negative, the cooldown is decreased. If the resulting cooldown would be negative, the cooldown is set to 0, i.e. the skill is ready to use after this node runs.
  • If Limit Maximum CD Time is Yes and CD exceeds the skill cooldown configured in the skill, cooldown is set to the value configured in the skill. For example, if the skill is configured for 20 seconds as pictured below and 30 was passed in to CD, the resulting cooldown after this node runs is 20.
  • If the skill was in cooldown when this node runs, the cooldown button will retain the displayed maximum CD it was using. Below example shows a case where skill cooldown is 20, CD is 5, and the cooldown is 10. If the skill was not in cooldown when this node runs, the cooldown button will set the displayed maximum CD as the new cooldown. Below example shows the same case as before.

Performance

This node took ~4 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
