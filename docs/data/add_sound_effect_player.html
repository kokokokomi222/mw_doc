Add Sound Effect Player

Plays a sound.

Input Parameters

  • Target Entity (Entity) - Entity to play the sound from. It must have an SFX Player component.
  • Sound Effect Asset Index (Integer) - ID of the sound effect. e.g. 50925
  • Volume (Integer) - Volume of the sound. 0 means mute, 100 means full gain. This value scales the amplitude linearly. Must be between 0 and 100, inclusive.
  • Playback Speed (Floating Point Numbers) - Speed to play the sound at. 1.0 means default speed. Must be between 0.5 and 2.0, inclusive.
  • Loop Playback (Boolean) - If Yes, loop the sound, repeating it indefinitely.
  • Loop Interval Time (Floating Point Numbers) - Amount of silence before looping the sound. Unit is seconds.
  • 3D Sound Effect (Boolean) - If Yes, play the sound using 3D sound effect, applying panning and distance based attenuation.
  • Range Radius (Floating Point Numbers) - Radius of the 3D sound effect. The sound will not be heard outside the range. Unit is in meters. Must be between 1.0 and 1000.0.
  • Attenuation Mode (Enumeration) - One of Linear Attenuation, Fast Then Slow, and Slow Then Fast
  • Attachment Point Name (String) - Name of the attachment point on the entity. e.g. "GI_RootNode"
  • Attachment Point Offset (3D Vector) - Offset relative to the entity's attachment point. This transformation is in the entity coordinate space, taking entity transform into consideration.

Output Values

  • SFX Player ID (Integer) - ID of the resulting sound player if the sound is looping. -1 if the node failed or if the sound is not looping.

Usage

Miliastra can play sound effects from entities. Sounds can be added to entities from SFX Player component, and it will be played when the entity is created without having to use node graphs.

Use this node to play sounds from node graph. If you just need to play a sound once as a 2D effect, use Player Plays One-Shot 2D Sound Effect instead which does the same thing but much simpler. If you want to play music, use Set Player Background Music instead.

Sound effects in Miliastra are capable of some basic 3D sound features. It can do attenuation: making the sound softer as players get further away from the sound source. It also utilizes stereo channels to give players the sense of the direction of the audio source.

The returned value SFX Player ID can be used by

  • Close Specified Sound Effect Player - to stop the sound
  • Start/Pause Specified Sound Effect Player - to pause/resume the sound
  • Adjust Specified Sound Effect Player - to adjust the volume or the playback speed

Example

In this example, the sound with ID 50662 (Object_Loop SFX_Hum_04) starts playing at this entity when the tab is selected by a player. It plays at volume 50 (half the amplitude, i.e. ~6dB softer than full gain). It plays at twice the speed. It will loop the sound with 0.5 second silence between the loops (so it will play for 2.5 seconds, pause for 0.5 seconds, and then repeat the cycle). It plays as a 3D effect, so the sound will be heard louder if the player is closer to the entity. The 3D sound radius is set to 50 meters, so if the player is more than 50 meters from the sound player, the sound will not be heard by the player. Attenuation mode is set to Slow Then Fast, so the sound will get softer as player move away from the entity but the rate at which the sound gets softer is low at first but increase as the distance increases. The sound player is attached 1 meter higher than GI_RootNode attachment point. The 1 meter here is not affected by the entity's zoom (see notes for more detail).

Notes

  • Sound Effect Asset Index can be selected by clicking on the magnifier icon on the right. Clicking the play button plays the sound for preview.
  • If Target Entity is not an entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have the SFX Player component, this node raises "Entity component does not exist" error.
  • Stage entity and the player entities cannot have SFX Player component.
  • If Sound Effect Asset Index is not an ID for a sound, this node is no-op.
  • If Volume is negative or if it exceeds 100, this node is no-op.
  • Because Volume scales the amplitude linearly, it does not scale linearly with human perception, which is logarithmic. If you are making a volume slider, you may want to account for this. See Adjust Player Background Music Volume for an example.
  • Playback Speed is less than 0.5 or greater than 2.0, this node is no-op.
  • Unlike music, Playback Speed appears to apply pitch correction. Faster speed does not mean that the pitch is higher.
  • If Loop Playback is Yes and Loop Interval is negative, this node is no-op. If Loop Playback is No, Loop Interval can be any value.
  • One entity can only have 10 looping sound effect players at once. If this node is called with Loop Playback set to Yes while the entity already has 10 looping sound effect players, this node is no-op.
  • If 3D Sound Effect is Yes and Range Radius is less than 1.0 or greater than 1000.0, this node is no-op. If 3D Sound Effect is No Range Radius can be any value.
  • The attenuation curve approximately looks like the following: Fast Then Slow eases out while Slow Then Fast eases in. The attenuation factor is multiplied to the amplitude of the sound. The attenuation factor should be inversely proportional to the distance in physics, so Fast Then Slow may be the most physically accurate one out of the three.
  • If 3D Sound Effect is Yes and Attachment Point Name is not a name for an attachment point of the entity, this node succeeds in making a sound player, but does not play the sound.
  • Unlike visual special effects, Attachment Point Offset is not affected by the entity's zoom, but it is affected by location and rotation. The preview of the player location and range preview in the SFX Player component is incorrect when the entity has non-default zoom. You may want to define a custom attachment point instead of using Attachment Point Offset.

Performance

This node took ~9 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
