Get Player Remaining Revives

Gets the revive count for a player.

Input Parameters

  • Player Entity (Entity) - Player entity to get the revive count from.

Output Values

  • Remaining Times (Integer) - Player's revive count.

Usage

Revive count can be configured for players in player template detail panel. Once a player runs out of revives, the player sees the below screen and the player can no longer revive.

Use this node to get the revive count for a player.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error and returns 0.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading, and returns 0.
