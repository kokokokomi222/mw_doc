When Tab Is Selected

Triggers when tab is selected.

Output Values

  • Event Source Entity (Entity) - Entity with the tab component
  • Event Source GUID (GUID) - GUID of above Entity. 0 if the entity was created dynamically.
  • Tab ID (Integer) - ID of the tab. e.g. 1
  • Selector Entity (Entity) - Character entity that selected the tab

Usage

Tab component is used to give selectable options to players. Use this node to listen to the event where tab is selected by a player.

Notes

  • Event Source Entity and Event Source GUID may not be the same as the self entity, if it was forwarded by Forwarding Event.
  • The maximum number of tabs that can be added to one entity is 10.
  • Selector Entity is the character entity, not the player entity. In order to get the player entity, use Get Player Entity to Which the Character Belongs.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
