Remove Key Value Pairs from Dictionary by Key

Remove a key-value pair from a dictionary.

Input Parameters

  • Dictionary (Generic) - Dictionary to modify
  • Key (Generic) - Key to remove from the dictionary

Usage

Use this node to remove a key-value pair from a dictionary.

Example

In this example, we have a node graph variable dictionary named round_score which stores key-value pair of player entity and player's score. On Player Disconnected signal, we remove the player's score from the dictionary.

Notes

  • Changing the type of Key will change the type of Dictionary, and vice versa.
  • If Key is not a key in Dictionary, this node is no-op.
  • If Key is left empty, it is considered to be the default value of that type.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~9 units on average. For a dictionary with 100 key-value pairs, this node took ~80 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
