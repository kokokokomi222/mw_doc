Allow/Forbid Player to Revive

Sets whether the player can revive.

Input Parameters

  • Player Entity (Entity) - Player entity to set the revivability for.
  • Allow (Boolean) - If Yes, player can revive given enough number of revives. If No, player cannot revive.

Usage

In player template details panel, player can be configured to allow or disallow revive. Use this node to set this revivability configuration. If "Allow Revive" is set to No, the player cannot revive regardless of the number of revives. Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading.
  • If "Allow Revive" is toggled on, configurations in the player template details panel all applies, including revive duration, ruvive count, revive points, etc.
