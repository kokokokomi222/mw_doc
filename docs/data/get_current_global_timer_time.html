Get Current Global Timer Time

Gets the time of a global timer.

Input Parameters

  • Target Entity (Entity) - Entity to pause the global timer from.
  • Timer Name (String) - Name of the timer as specified in Timer Management.

Output Values

  • Current Time (Floating Point Numbers) - Number of seconds on the global timer.

Usage

Use this node to get the time from a global timer.

Example

In this example, we compute a score for the player that selected the tab, giving 100 points for every second left in the global timer named Round Timer.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error and returns 0.
  • If Target Entity does not have the global timer component, this node raises "Entity component does not exist" error and returns 0.
  • If Timer Name is not the name of a global timer defined in Timer Management, this node returns 0.
  • If the global timer is not running, this node returns 0.
  • This node works for paused global timer, getting the time value when the global timer was paused.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
