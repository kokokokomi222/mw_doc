Set Player to Leave Control Motion Device

This server node is only available in Beyond Mode.

Set a player to leave a control motion device entity.

Input Parameters

  • Player Entity (Entity) - Player entity to leave a control motion device

Usage

Luna VIII introduced control motion devices. An entity can have a control motion device component, then this entity's movement can be controlled directly by players instead of controlling Manekin/Manekina character. This feature can be used to create a vehicle that can be driven by players.

Use this node to make a player leave a control motion device entity. The player's character will appear near the control motion device entity at the location as configured in the component, and the camera will get back to the character. This undoes Set Player to Follow Control Motion Device.

Example

We have a node graph mounted on the player. When the interactive button is pressed by the player, we make the player leave the following control motion device entity, return the player's control back to the player's character, and then hide the interactive button.

Notes

  • Player Entity must be a player entity. If Player Entity is a stage, character, object, or creation entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • The location at which the character appears after leaving can be configured in the control motion device component to a custom attachment point. This is where the character's GI_AvatarRoot ends up at (located at between two feet).

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
