Query If All Player Characters Are Down

Checks whether all characters are downed for a player.

Input Parameters

  • Player Entity (Entity) - Player entity to check the characters for.

Output Values

  • Result (Boolean) - Yes if the player's characters are all down. No otherwise.

Usage

Use this node the check whether all characters of a player are downed.

Example

In this example, we count all players who have at least one character alive and print the count.

Notes

  • During a character death animation, this node returns No.
  • During revive loading screen, this node return No.

Performance

This node took ~2 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
