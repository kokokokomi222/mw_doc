Query Dictionary Value by Key

Returns the value corresponding the key in the dictionary.

Input Parameters

  • Dictionary (Generic) - The dictionary to query the value from
  • Key (Generic) - Key in the dictionary

Output Values

  • Value (Generic) - Value that corresponds the key in the dictionary

Usage

This is the primary query on dictionaries, getting the value from the key. You will likely use this node if you are using a dictionary.

Example

In this example, we have a node graph variable dictionary named round_score which stores key-value pair of player entity and player's score. When a player selects the tab, we get the current score of the player from the dictionary using Query Dictionary Value by Key, then set the new score of the player by adding 100.

Notes

  • If Key is not a key in the dictionary, this node returns the default value of the type of Value. To properly test whether a key is in the dictionary, use Query If Dictionary Contains Specific Key instead.

Performance

This node is slow in load testing. This is maybe because the debugger stores and/or serializes the dictionary, but we are unsure how much faster it runs in release. For a dictionary with 10 key-value pairs, this node took ~12 units on average. For a dictionary with 100 key-value pairs, this node took ~80 units on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
