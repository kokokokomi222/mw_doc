Activate/Disable Native Collision Climbability

Sets native collision climbability.

Input Parameters

  • Target Entity (Entity) - Object entity to set the climbability for.
  • Activate (Boolean) - If Yes, climbability is enabled. If No, it is disabled.

Usage

Native collision is used so that characters can collide with the entity. Object entity can have its native collision configured in the entity details panel.

Use this node to set the climbability of the native collision. Characters will be able to climb this entity if climbability is enabled.

Notes

  • If Target Entity is not an exiting entity, this node raises "Entity does not exist" error.
  • If Target Entity is not an object entity, this node is no-op.
  • If the native collision is currently disabled, this node still modifies the climbability. For example, the entity is not climbable after the below node graph executes even if it was initially climbable.
