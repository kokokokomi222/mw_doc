Close Specified Sound Effect Player

Stops a looping sound effect player.

Input Parameters

  • Target Entity (Entity) - Entity that has the looping sound effect player.
  • SFX Player ID (Integer) - ID of the looping sound effect player.

Usage

Use this node to stop a looping sound effect played by Add Sound Effect Player. It will immediately stop making the sound and the sound effect player will be removed from the entity.

SFX Player ID can be obtained from Add Sound Effect Player.

Example

In this example, we stop the sound when the signal named Stop Sound is received.

Notes

  • If Target Entity is not an entity, this node raises "Entity does not exist" error.
  • If Target Entity does not have the Sound Effect Player component, this node raises "Entity component does not exist" error.
  • If SFX Player ID is not an ID for a currently playing looping sound effect, this node is no-op.

Performance

This node took ~4 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
