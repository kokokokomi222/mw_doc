Stop Global Timer

Stops a global timer.

Input Parameters

  • Target Entity (Entity) - Entity to stop the global timer from.
  • Timer Name (String) - Name of the timer as specified in Timer Management.

Usage

This node stops a global timer. This removes the global timer completely from the entity: the time value held by the global timer will be lost, and any UI or nameplate showing the timer will disappear.

Use Pause Global Timer instead if you just want to stop ticking the timer, but keep the time value and display the timer.

Notes

  • If Target Entity does not exist, this node raises "Entity does not exist" error and continues execution.
  • If Target Entity does not have the global timer component, this node raises "Entity component does not exist" error and continues execution.
  • If Timer Name is not the name of a global timer defined in Timer Management, this node is no-op.
  • If there is no global timer named Timer Name running on the entity, this node is no-op.

Performance

This node took ~5 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
