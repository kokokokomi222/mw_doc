Play Timed Effects

Play a timed effect at an entity.

Input Parameters

  • Special Effects Asset (Config ID) - ID of the timed effect to play. e.g. 10002012
  • Target Entity (Entity) - Entity to play the effect at.
  • Attachment Point Name (String) - Name of the attachment point on the entity. e.g. "GI_RootNode"
  • Move With the Target (Boolean) - If Yes, the effect will follow the entity. If No, the effect will remain where it started playing.
  • Rotate With the Target (Boolean) - If Yes, the effect will rotate with the entity. If No, the effect's rotation will remain fixed.
  • Location Offset (3D Vector) - Offset relative to the entity's attachment point. This transformation is in the entity coordinate space, taking entity transform into consideration.
  • Rotation Offset (3D Vector) - Rotation relative to the entity's attachment point. This transformation is in the entity coordinate space, taking entity transform into consideration.
  • Zoom Multiplier (Floating Point Numbers) - Zoom multiplier for the effect.
  • Play Built-In Sound Effect (Boolean) - If Yes, the effect will play a built-in sound associated with the effect, if one exists.

Usage

This node is used to play timed effect, which is a visual special effect that plays once and stops. To play looping effect, use Mount Looping Special Effect instead. To play sound effect, use Start/Pause Specified Sound Effect Player or Player Plays One-Shot 2D Sound Effect instead.

Effects may not be visible when you preview them for various reasons. Some effects are too small or too large to be seen. Some effects must be placed near ground for it to be visible. Some effects also come with built-in sound with can be played with Play Built-In Sound Effect. See the timed effect browser for details on each timed effect.

Notes

  • Special Effects Asset can be selected by clicking on the magnifier icon on the right. Clicking the play button plays the effect on stage as a preview (although it may be difficult to see for some effects).
  • If Special Effects Asset is not an ID for a timed effect, this node is no-op.
  • If Target Entity does not exist, this node raises "Entity does not exist" error.
  • If Target Entity does not have the "VFX Playing" component, this node raises "Entity component does not exist" error.
  • If Target Entity has model visibility turned off from the entity details panel or Activate/Disable Model Display, the timed effect does not show.
  • If Attachment Point Name is not a name for an attachment point of the entity, this node raises "Entity component does not exist" error, which is misleading.
  • The position of the played timed effect uses the entity coordinate system. Any offset specified with Location Offset or Rotation Offset takes effect after entity transformation is applied.
  • Entity zoom does not affect the effect size, but it does scale Location Offset. For example, if the Target Entity has a zoom of (1.0, 1.5, 2.0) and Location Offset is (3.0, 5.0, 7.0), then the resulting offset in the stage coordinate space is (3.0, 7.5, 14.0).
  • If entity is destroyed while the effect is playing, The effect stops playing.
  • If there are too many effects already, this node may fail, but this needs more testing.
  • Not all parts of the effect may scale by Zoom Multiplier. Some parts may even be visible even when Zoom Multiplier is 0 or negative.
  • Appearance of effects can depend on camera location.

Performance

This node took ~9 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
