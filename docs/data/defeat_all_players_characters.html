Defeat All Player's Characters

Downs all characters of a player.

Input Parameters

  • Player Entity (Entity) - Player entity to down all characters for.

Usage

Use this node to down all characters owned by a player.

Use Destroy Entity instead to down just one character.

Example

In this example, we down all characters of a player when the player selects the tab. The player's active character will play the death animation and then the revive screen will be shown (if configured for revive screen).

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading.

Performance

This node took ~180 units to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
