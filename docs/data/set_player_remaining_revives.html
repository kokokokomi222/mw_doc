Set Player Remaining Revives

Sets the revive count for a player.

Input Parameters

  • Player Entity (Entity) - Player entity to set the revive count for.
  • Remaining Times (Integer) - Revive count to set.

Usage

Revive count can be configured for players in player template detail panel. Once a player runs out of revives, the player sees the below screen and the player can no longer revive.

Use this node to set the revive count for a player.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading.
  • If Remaining Times is negative, this node is no-op.
  • If this node modifies the revive count to a positive number while the player is in the "Unable to Act" revive screen due to having zero revive count, the player gets the revive count and is able to revive.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
