Query Player's Currently Activated Control Motion Device List

This server node is only available in Beyond Mode.

Gets the list of control motion devices activated on a player.

Input Parameters

  • Player Entity (Entity) - Player entity

Output Values

  • Control Motion Device Entity List (Entity List) - List of control motion device entities that are activated on the player

Usage

Luna VIII introduced control motion devices. An entity can have a control motion device component, then this entity's movement can be controlled directly by players instead of controlling Manekin/Manekina. This feature can be used to create a vehicle that can be driven by players.

This node lets you query the control motion device entities that are controlled by the player.

Example

We have a node graph mounted on a player. If an interactive button is pressed by the player, we iterate through all control motion device entities controlled by the player, and play a timed effect at these entities.

Notes

  • Player Entity must be a player entity. If Player Entity is a stage, character, object, or creation entity, this node raises "Entity does not exist" error (can be misleading, because the non-player entity may exist).
  • The length of Control Motion Device Entity List cannot exceed 3.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tend to take a bit longer.
