Check Whether Player Cursor Is Active

Returns cursor visibility.

Input Parameters

  • Player Entity (Entity) - Player entity to check the cursor visibility for.

Output Values

  • Activate (Boolean) - Yes if the player's cursor is visible.

Usage

Luna VIII introduced various features involving cursors. Cursor visibility can be set in player setting or by Set Player's Cursor to Always Visible. This node can be used to get this cursor visibility in node graph.

Notes

  • If Target Entity is not a player entity, this node raises "Entity does not exist" error (can be misleading because the entity may exist) and returns No.
  • Making the cursor visible by holding the alt key does not count as cursor visibility for this node.

Performance

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
