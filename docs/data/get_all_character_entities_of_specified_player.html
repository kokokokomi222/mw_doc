Get All Character Entities of Specified Player

Gets the list of characters owned by the player.

Input Parameters

  • Player Entity (Entity) - Player entity.

Output Values

  • Character Entity List (Entity List) - List of character entities owned by the player.

Usage

Use this node to get the character entities from a player entity. Use Get Player Entity to Which the Character Belongs to get the player entity from a character entity.

In beyond mode, this list will contain exactly one character.

Example

In this example from a beyond mode stage, we listen to when the player completes teleportation then we play a timed VFX at the character. Note that "Player Entity" from When Player Teleport Completes is a player entity, but Play Timed Effects wants the character entity, so we had to "convert" the player entity to character entity.

Notes

  • If Player Entity does not exist, this node raises "Entity does not exist" error and returns the empty list.
  • If Player Entity is not a player entity, this node raises "Entity does not exist" error, which is misleading, and returns the empty list.

Performance

This node took ~1 unit to run on average.

Performance may vary for various reasons. These numbers are just for giving a sense of rough magnitude. Performance may differ from profiling in a test play when playing a published stage. First execution of a node within a node graph execution tends to take a bit longer.
